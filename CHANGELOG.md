# Changelog

## 0.1.0 — 2026-10-06

- Added a React/TypeScript/Vite A2UI playground with Adobe Spectrum v3.
- Added a versioned 15-component catalog and design-system adapter contract.
- Implemented the documented subset of A2UI v0.9.1 surface, component, data and action messages using upstream envelope schemas.
- Added interactive discovery, shortlist comparison, and editable enquiry examples with fictional fixture data.
- Added a deterministic demo transport and optional server-side Gemini development endpoint.
- Added schema/graph/input bounds, cancellation, error recovery, local form state and explicit draft review.
- Added JSON export, protocol/data/action inspection, light/dark themes and mobile layouts.
- Added unit/server and browser journey tests, rendered design captures, sample JSON, architecture and adapter-extension documentation.
- MUI and shadcn/ui are planned adapter targets, not implemented in this release.
